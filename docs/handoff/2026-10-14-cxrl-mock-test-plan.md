# CXR-L Mock 通信调试：真机验收计划

开发范围：官方 SDK 1.1.2 / CUSTOM_VIEW，手机明确确认 → 真实拍照 → 有效图片 → Mock → 眼镜文字；用户已同意手机按钮用于当前通信调试。眼镜实体键接入与正式盲人主流程不因本调试 APK 完成而被标为完成。

## 开始前

- 按 #19 记录两端型号/API/系统、眼镜固件和官方 App 地区/版本；官方 App 自己能连接眼镜并拍照。
- 按 [phone-l 说明](../../apps/device-experiment/android/phone-l/README.md)构建/安装 v0.2.0；保留 APK SHA-256、源码提交、SDK 和构建版本。安装启动不等于连接成功。
- 核对授权返回、连接回调、Session Started 和眼镜初始探针文本。若 binder/连接失败，记录最早失败阶段，同版本官方 Sample 对照，保持 #21 未验收。
- 此方案不部署 Gemma/TTS/地图 Key，不更改系统助手权限；先验证本地通道，再测试断开互联网（保持所用本地连接）。

## 单次闭环

1. 选择 cold/warm 并记录固件；关闭旧 Session，重新授权、手动连接。
2. 打开拍照确认窗口，确认后拍摄现场明确可核对的对象。手机预览应与现场一致，尺寸/格式/大小应真实。
3. 核对眼镜显示 `Mock：图片已收到 … #<请求代号>`，与手机当前请求一致；仅在实际看见后点人工确认。
4. 关闭 Session，检查资源释放；导出 JSON。图片不写相册、不上传；共享证据前移除个人信息。

## 失败与恢复

| 操作 | 期望行为 | 真机结果 |
| --- | --- | --- |
| 确认窗口点取消或等待 30 秒 | 不调用相机；旧确认不能使用 | 待测 |
| 确认后取消/断连/SDK 暂停 | 作废请求、拒收旧图片；旧 Session 关闭 | 待测 |
| 拍照失败、空/损坏图片、接收超时 | 不生成 Mock 成功，显示真实失败阶段 | 待测 |
| Mock 显示 API 拒绝/超过 20 秒 | 不计可见成功；结束旧 Session | 待测 |
| 手机后台/灭屏、眼镜灭屏/返回桌面 | 撤销并停止；返回不自动拍照或重连 | 待测 |
| 官方助手唤醒/中断、摘下眼镜 | 撤销本次确认；不擅改系统组件 | 待测 |
| 手动恢复后重新授权/连接/确认 | 新请求完成闭环，旧结果不进入新任务 | 待测 |
| 退出宿主 | 检查 SDK close/回调解绑、相机和连接释放 | 待测 |
| 眼镜真实实体键 | 当前 CUSTOM_VIEW 无公开回调；核对支持路线，仍未接入验收 | 待确认 |

已经进入厂商 SDK 的调用不一定立即可中断。若 Binder 卡死，本地超时/取消不代表原生 close 已完成，需保留失败证据并定位厂商链路。

## 重复样本

冷启动和热运行分别采样，例如各 20 次；每个 SDK Session 只拍照一次。不要重复导出重叠请求后重复计数。保留失败，不能只选择成功样本。用汇总工具检查成功率、P50/P95、最大值和失败阶段。人工确认时间不是首次显示时间；若需要精确可见延迟，用外部录像说明测量方法。眼镜曝光/首分片时间当前 SDK 不公开，不填写虚构数值。
