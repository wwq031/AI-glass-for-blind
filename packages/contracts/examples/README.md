# P0 合同样例

这些样例用于组员对齐字段和编写 Fake，不代表固定的真实设备数据。时间、ID 和哈希在测试中应由夹具生成器替换。

- `speech-input-destination.json`：用户说出目的地
- `destination-candidates.json`：地图返回候选 POI
- `navigation-intersection-approaching.json`：导航确认接近路口
- `device-event-button.json`：用户确认拍摄
- `observation-result-intersection.json`：视觉返回路口事实
- `crossing-advisory-recheck.json`：Agent 要求等待并重查
- `contract-error-capture-failed.json`：拍摄失败且可重试
